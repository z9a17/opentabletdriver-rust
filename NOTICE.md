# Radial Follow source notice

`crates/otd-core/src/radial_follow.rs` is a Rust port of AbstractQbit's `RadialFollowCore.cs` and `RadialFollowSmoothingTabletSpace.cs` from the [RadialFollow 0.3.0 release](https://github.com/AbstractQbit/AbstractOTDPlugins/tree/0.3.0/RadialFollow). The original plugin is by AbstractQbit and is licensed under GPL-3.0-only. This port keeps the original tablet-space filter name, OpenTabletDriver configuration path, setting names, curve, and 50 ms reset behavior. Its changes are the Rust representation, `std::time::Instant` timing, and direct integration into this driver without the .NET plugin interface.

The pre-existing driver files were released under LGPL-3.0-only. Their license text is retained in [LICENSE.LGPL-3.0](LICENSE.LGPL-3.0). The combined 0.3.0 executable includes the GPL-3.0-only filter and is conveyed under [GPL-3.0-only](LICENSE).

## Tablet configuration data

`crates/otd-core/tablets` holds OpenTabletDriver's **359 tablet configuration files**, copied unchanged from [`OpenTabletDriver.Configurations/Configurations`](https://github.com/OpenTabletDriver/OpenTabletDriver/tree/126f4828564abb673d39e97a093fd815aab335c2/OpenTabletDriver.Configurations/Configurations) at `v0.6.8-rc1`, revision `126f4828564abb673d39e97a093fd815aab335c2` (OpenTabletDriver contributors, LGPL-3.0-or-later). They reference 54 native parser types. The executables embed this data; `scripts/update-tablet-database.py` copies it, and `crates/otd-core/tablets/SOURCE` records its origin. Earlier catalog inventories remain historical evidence.

## Optional .NET compatibility bridge

The `data/compat` bridge uses the real OpenTabletDriver assembly names and contracts. Core, Desktop, UX and Console source hosts originate from the [0.6.7 source baseline, revision `736003ed72c8bbb28033b039d5a0bb76c344145c`](https://github.com/OpenTabletDriver/OpenTabletDriver/tree/736003ed72c8bbb28033b039d5a0bb76c344145c), with documented host adaptations and selected [0.6.8-rc1 changes at `126f4828564abb673d39e97a093fd815aab335c2`](https://github.com/OpenTabletDriver/OpenTabletDriver/tree/126f4828564abb673d39e97a093fd815aab335c2). These are modified source builds targeting .NET 10 (`net10.0`) and assembly version 0.6.8; they are not unchanged 0.6.7 assemblies or complete replacements of all source with the RC tree. Per-component changes and preserved license attribution are recorded in `compat/UpstreamCore`, `compat/UpstreamDesktop`, `compat/UpstreamUX` (including GTK/macOS launchers), and `compat/UpstreamConsole` provenance files.

`compat/UpstreamPlugin` vendors the actual Plugin SDK from the RC commit above, retaining its 0.6.8 assembly identity and LGPL-3.0-or-later attribution. Two interfaces have compatibility default bodies for new initialization and rotation members so older direct implementors do not require those methods merely to load. Unsupported new operations fail explicitly. This modified SDK is not the unchanged NuGet Plugin DLL; its exact changes are listed in `compat/UpstreamPlugin/PROVENANCE.md`. Configurations and Native are exact **NuGet 0.6.8** packages whose repository source commit is the same RC revision. Configurations supplies original parser/concrete report types; Desktop supplies original settings, providers, presets and bindings. Package versions and transitive dependencies are locked in the compatibility projects' `packages.lock.json` files. Helpers use the native owner and hosted services; they do not start an upstream hardware daemon or duplicate its physical reader. Source implementation alone does not prove unchanged third-party plugin compatibility.

The closure includes Newtonsoft.Json, JetBrains.Annotations, MessagePack, Microsoft dependencies, Nerdbank.Streams, Octokit and SharpZipLib under MIT, HidSharpCore under Apache-2.0, and WaylandNET under ISC. Exact versions, authors, licenses and redistributed third-party notices are consolidated in `compat/THIRD_PARTY_NOTICES.txt` and packaged as `data/licenses/DOTNET-BRIDGE-NOTICES.txt`. The Desktop license/source provenance are separately included and hashed. The .NET hosting library `nethost.dll` is distributed under Microsoft's MIT license; its SDK license and third-party notices are under `data/licenses`. The .NET runtime itself is not bundled. The compatibility bridge and sample native plugin source are in this repository; the developer sample plugin is not included in runtime downloads. The original third-party RadialFollow DLL is used unchanged for tests and is not included in releases; users retain their original plugin and its licensing terms.

## Project application artwork

`resources/opentabletdriver.ico` is this project's blue tablet-and-pen icon, generated from `resources/opentabletdriver.svg` and `resources/opentabletdriver-small.svg` by `scripts/generate-app-icon.py`. It is embedded in both Windows executables and used by the native panel, under this project's GPL-3.0-only license.

The same ICO and its 256-pixel PNG image replace `compat/UpstreamUX/Assets/otd.ico` and `otd.png` in the packaged Linux/macOS frontends. These artwork overrides use the project's GPL-3.0-only license; the pinned upstream frontend source retains its LGPL-3.0-or-later attribution. See `compat/UpstreamUX/PROVENANCE.md`.
